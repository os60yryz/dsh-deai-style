## 三、为什么「纯排版」不能定罪（对 FN2-02 与 5.4 的正面回答）

红队第二轮指出「只有排版、没有套话」的 AI 回答得分恒为 0。我们加了受限出口（≥5 权重给 ≤25 分），但**没有**允许排版独立定罪，依据是第二轮实测的排版权重分布：

| 样本 | 排版权重 | 性质 |
| --- | --- | --- |
| AI 纯 bullet 列表 | 3.7 | 应当被抓 |
| AI 纯表格回答 | 4.0 | 应当被抓 |
| AI emoji 项目符号 | 5.33 | 应当被抓 |
| 人类干净步骤清单 | 5.34 | 不应当误伤 |
| 人类工作日志（行首 emoji） | 4.0 | 不应当误伤 |
| 人类会议纪要（行首标签） | 2.0 | 不应当误伤 |

AI 与人类的排版权重**完全重叠**：抽到最「AI 排版」的样本（5.33）仍低于最「工整」的人类样本（5.34）。任何「排版可单独定罪」的阈值都会同时误伤人类或漏掉 AI，所以这个维度只能作为观察项（≤25 分，永远进不了「中等」档）。

由此确定的边界（`tests/checks.mjs` 第 13.12 组用断言锁住）：

- 纯表格回答、纯 bullet 列表、纯编号步骤、纯标题层级 → 不定罪；
- 这些样本一旦带上任何语言套话（「综上所述」「不是…而是…」「- **标签**：」）就会命中规则，不在边界内；
- 卡片的落点：**排版是观察信号，用词与句式才是定罪证据**。

## 五、对 `round1-fix.md` 的更正（红队第二节 2.3）

2. 「长文整体免检已由 ×20 用例覆盖」——**表述过强**：×20 是等密度重复，只证明「密度不变时分数不随长度降」；稀释式长文分数仍会下降，且这是期望行为。原文已补注，并把「5 分」更正为实测的「1 分」。
3. 「`emoji-marker` 比例化避免了单次定罪 / 可独立成立」——**已作废**：第二轮把它降为 `format`。原文已加更正说明。
4. 「围栏配对已重写稳定」——**第一轮并未真正修好**：四反引号与 `~~~` 都失守，第二轮才改为按行扫描 + 长度配对。
